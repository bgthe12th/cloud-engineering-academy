
# Maven Cloud Engineering Academy

## Mission

Build practical cloud engineering expertise through real-world
infrastructure projects inspired by Maven Logistics.

## Learning Framework

R.E.A.L.

- Root: Learn fundamental cloud engineering concepts.
- Execute: Build solutions from real business requirements.
- Amplify: Document and publish engineering decisions.
- Land: Develop an employer-ready engineering portfolio.
